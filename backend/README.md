# Rustam Super Mart — Inventory Management System

## Run it
1. Extract the ZIP file.
2. Open the `rustam_inventory_management_system` folder in VS Code.
3. Double-click `index.html`, or use the VS Code Live Server extension.

## Included
- `logo.png` is the navbar logo (keep it in the same folder as `index.html`)
- Responsive dashboard
- Add, edit and delete products
- SKU uniqueness validation
- Quantity and reorder-level tracking
- Low-stock and out-of-stock alerts
- Stock adjustments (+/-)
- Search and category/stock filters
- Export inventory as CSV
- Stock activity log
- Browser localStorage persistence
- Demo starter products

## Important
This is a front-end demo. Data is saved in the current browser using localStorage. It does not have a shared database, user login, backups, or multi-device syncing. Clearing browser data can remove saved inventory. For real store use, connect a backend/database and add authentication and backups.
