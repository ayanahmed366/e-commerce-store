Rustam Super Mart - pictures instead of emojis
================================================
Open index.html in a browser (or host the folder as-is).

Pictures live in:
  images/collections/<collection-id>.svg
  images/products/<product-id>.svg
  images/placeholder.svg   (used when a picture is missing)

The included pictures are PLACEHOLDERS (name cards). To use real photos:
  1. Put your photo in the folder, e.g. images/products/med-1.jpg
  2. In products.js change  image: 'images/products/med-1.svg'  to  image: 'images/products/med-1.jpg'
Tip: use ~600px wide JPG/PNG/WEBP so pages load fast.

NOTE: the data key changed to rustamSuperMartStoreV3, so the site shows the new
default data on first open. Edits saved in the browser by the older version are not carried over.
